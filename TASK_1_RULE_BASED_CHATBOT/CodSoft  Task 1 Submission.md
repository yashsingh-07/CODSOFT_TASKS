Project Description

I developed a Python-based rule-driven chatbot named Alex.

Alex is designed as a sports knowledge assistant that responds to predefined questions about different sports, famous players, rules, scoring systems, tournaments, and sports terminology.

The chatbot uses Python "if/elif" conditional statements, functions, loops, string processing, and user input/output to identify keywords and provide appropriate predefined responses.

How It Works

The chatbot follows a rule-based approach.

User Input
     ↓
Convert input to lowercase
     ↓
Check predefined conditions
     ↓
Identify sport/topic
     ↓
Match keywords
     ↓
Generate predefined response
     ↓
Display response

For example, if the user asks about cricket, the program checks cricket-related keywords and then searches for specific topics such as famous players, formats, rules, or tournaments.
